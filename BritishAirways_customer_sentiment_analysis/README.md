✈️ British Airways Customer Sentiment Analysis:

Project Overview:

This project is an end‑to‑end customer sentiment analysis of British Airways reviews sourced from AirlineQuality.com. The goal was to transform raw, unstructured text into actionable insights that highlight customer satisfaction trends and operational pain points.

Purpose: 

The analysis classified customer reviews into positive, negative, or neutral categories using polarity and sentiment scoring techniques. These insights helped identify what British Airways was doing well and where customer experience improvements were needed the most.

---------------------------------------------------------------------------------------------------------------------------
Tools & Technologies:

• Python Libraries: BeautifulSoup (web scraping) • Pandas (data cleaning & transformation) • NumPy (data manipulation) • NLTK (text preprocessing: tokenization, stopword removal, lemmatization) • TextBlob (sentiment & polarity scoring) • Matplotlib & Seaborn (EDA visualizations)

• Data Processing: Excel • Power Query

• Environment: Google Colab

• Visualization & Reporting: Power BI

----------------------------------------------------------------------------------------------------------------------------
Skills Demonstrated: 

• End‑to‑end data pipeline development — from web scraping to cleaning, analysis, and dashboarding

• Web scraping & automated data extraction using BeautifulSoup

• Text preprocessing for NLP (tokenization, stopword removal, lemmatization) with NLTK

• Lexicon‑based sentiment and polarity analysis using TextBlob

• Exploratory data analysis (EDA) to uncover patterns in customer sentiment

• Interactive dashboard design & visualization in Power BI

• Data storytelling & insight communication to highlight customer experience trends and operational pain points
